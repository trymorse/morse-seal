# Security

If you find a way to make `morse-seal` send a content request unsealed, seal it to a key that no verified attestation document names, accept a document that `enclave_pins.json` does not list or lists as revoked, or trust an image whose `morse-enclave` tag is missing or lists other measurements, report it privately. Do not open a public issue.

Report it through this repository's **Security** tab, under **Report a vulnerability**, or by email to hello@trymorse.ai. Say which tag you looked at and how to reproduce the problem.

We tell you what we found, and when a fix ships we credit you in its release unless you ask us not to.
